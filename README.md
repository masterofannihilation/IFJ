# Compiler for simplified Swift
This project is a compiler for a simplified version of the Swift programming language. The compiler takes source code and generates an intermediate code for interpreter.

### Features

- **Lexical Analysis**: Tokenizes the source code into lexical units. \
- **Syntax Analysis**: Parses the tokenized input into a syntactical structure (abstract syntax tree). \
- **Semantic Analysis**: Performs type checking and ensures semantic correctness. \
- **Code Generation**: Translates the parsed code into intermediate representation.
